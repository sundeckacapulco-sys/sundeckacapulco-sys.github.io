DAVID OS es un entorno personal para organizar y disfrutar archivos de una biblioteca propia. Su conexión con Google Drive utiliza rclone en el equipo del usuario para consultar y leer archivos autorizados.

Uso personalConexión localOAuth de solo lectura

Cómo funciona la conexión

01 / AUTORIZAR

El permiso se concede en Google

La cuenta se autoriza mediante el navegador y el cliente de escritorio de rclone. Esta página no inicia ese proceso ni recibe contraseñas, códigos o tokens.

02 / CONSULTAR

rclone lee desde el equipo

La conexión OAuth aquí descrita solicita acceso de solo lectura a los metadatos y al contenido de Drive. El permiso puede alcanzar todos los archivos accesibles para la cuenta; no se limita técnicamente a una sola carpeta.

03 / UTILIZAR

Los archivos se usan localmente

El equipo puede reproducir contenido por streaming o conservar copias, cachés y una biblioteca local según las funciones utilizadas. Esta web no almacena esa biblioteca ni sirve sus archivos.

La página informa; tu equipo conecta

No necesitas introducir credenciales ni tokens aquí. No hay un botón para conectar Drive, un servidor de autorización ni una carga de archivos. DAVID OS es un proyecto personal independiente de Google, GitHub, rclone y Valve.
