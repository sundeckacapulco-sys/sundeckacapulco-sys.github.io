# DAVID OS — sitio informativo

Página estática independiente del código de DAVID OS. Incluye presentación, privacidad y condiciones de uso. No conecta cuentas ni recibe archivos, credenciales o tokens.

Para GitHub Pages: publicar estos archivos en un repositorio público nuevo y seleccionar la rama `main`, carpeta raíz, como origen de Pages. Los enlaces relativos admiten una URL de proyecto.

El alojamiento gratuito no equivale a aprobación de Google OAuth. Comprobar antes el dominio autorizado y su titularidad con la cuenta propietaria del proyecto. No añadir aquí configuraciones, registros, secretos ni código privado. La política describe el cliente propio con permiso `drive.readonly`.
